# Demo 视频脚本

建议时长：4–6 分钟。录制前关闭无关窗口和通知，浏览器缩放保持 100%。

## 0:00–0:30 项目定位

口播：

> 很多工具只负责生成，但作者还需要知道改编依据、是否遗漏、结果是否可信。溯源剧本工作台让小说改编结果可控制、可验证、可追溯。

展示：

- 首页完整界面。
- 顶部“离线规则模式（不调用 AI）”标签。
- 三步流程：输入检查、本地生成、溯源审阅。

## 0:30–1:30 导入与输入检查

操作：

1. 展示预置三章小说。
2. 点击“解析并检查”。
3. 展示章节数、字符数、章节标题和输入问题。

口播重点：

- 硬性要求是至少 3 章。
- 系统不会把空章或不合格输入静默送去生成。

## 1:30–3:30 可信生成与审阅

操作：

1. 点击“生成结构化剧本”。
2. 切换不同场次。
3. 展示来源原文摘录、来源事件、来源章节与改编动作。
4. 打开事件覆盖矩阵。
5. 打开质量门禁，展示覆盖率、来源追溯率和通过状态。

口播重点：

- 离线模式不调用 AI，不伪造无法证明的人物和具体地点。
- 每个场次都能回到真实原文证据。
- 覆盖矩阵用于发现遗漏，质量门禁用于阻止不可信结果通过。

## 3:30–4:20 YAML 与验证包

操作：

1. 打开“原始 YAML”。
2. 点击“下载剧本 YAML”。
3. 点击“下载验证包”。

口播重点：

- 剧本 YAML 符合项目定义的 Schema。
- 验证包额外包含原文侧车数据，可独立复核证据链。

## 4:20–5:00 七牛 AI 与工程质量

展示：

- 未配置时七牛 AI 按钮明确禁用。
- `docs/ai-provider.md` 的可信边界。
- GitHub PR 列表和 Actions 测试结果。

口播：

> 配置合法七牛 API Key 后，AI 只能在确定性骨架内润色。它不能修改来源 ID、证据位置或哈希，动作文本必须保留来源证据，最终仍需通过质量门禁。仓库不包含任何真实密钥。

不要声称已完成真实七牛线上调用，除非录制前已用自己的合法 Key 实测成功。

## 录制检查

- 画面中不出现 API Key、账号密码、GitHub token 或代理配置。
- 至少展示一次真实解析、真实生成、真实证据和质量门禁。
- 不使用固定截图冒充实时运行。
- 视频结尾展示仓库地址和 README 快速启动方式。
